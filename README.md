# Sound Effects for the Captain is Dead

This repo's HTML is served on github: [oldgit.github.io/uss-unfortunate](https://oldgit.github.io/uss-unfortunate/).

A simple HTML page with a responsive web design to render on mobile and desktop.
The page consists of buttons which play sound files from a famous sci-fi show to enhance playing a board game.

Thanks must go to [trekcore.com/audio](https://www.trekcore.com/audio/) for the sound files.

The page uses HTML, CSS and plain Javascript.
No Javascript frameworks, nor node/npm libraries are required.

However once the repo is cloned locally, the HTML can be served easily by running: `npx serve .`
(IMO easier than installing a webserver like nginx.)

## Further details

The text "The Captain is Dead" plays the sound: ./assets/deadjim.mp3.

The button name to sound filename links are as follows:

- Alert - ./assets/alert.mp3
- Damage - ./assets/damage.mp3
- External Scanners - ./assets/scanners.mp3
- Comm System - ./assets/comms.mp3
- Shields - ./assets/shields.mp3
- Torpedo tube - ./assets/torpedo.mp3
- Teleporter - ./assets/teleporter.mp3
- Jump Core - ./assets/warpcore.mp3
- Win - ./assets/warpaway.mp3
- Lose - ./assets/warpcore-collapsed.mp3
